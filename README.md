# SD-WAN-Advanced

SD-WAN uses 5 pillar approach:

1. Underlay
2. Overlay
3. Routing
4. ff
5. fff

-- Under Lay --

under lay is the physical connectivity could be physical routers, switches, 5G, MPLS, DIA, FiberInternet etc

-- Overlay --

Overlay is the logical / virtual connectivity we use it connect branches, AD-VPN tunnels, IPSec. 

-- Routing --

These are the routing protocols. 

-- Security --

ACLs, policies. 

-- SD-WAN Terminologies --

1. SD-WAN zones are different group of members. Members combine and create a zone.
2. SD-WAN Members, are the nodes under the zones.
3. Performance SLAs, these are the health checks. Performance metrics..
4. Bandwidth, means speed of the link.
5. Congestion, means exceeding the maximum bandwidth.
6. Delay, means latency the total time of travel of a packet from source to dest.
7. Jitter, means unusual uneven packet arrival time. Delay between the packets. A->B--->C
